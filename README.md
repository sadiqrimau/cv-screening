# CV Screening — landing page

One-page site for **Sadiq Solutions — CV Screening for Recruitment Teams**.

A recruitment team sends an applicant pool; they get back a ranked shortlist with
a stated reason for every candidate, plus a list of who was cut and why.

- `index.html` — the entire site. No build step, no dependencies.

## Deploy

Netlify, publish directory `/` (the repo root). Any push to `main` redeploys.
